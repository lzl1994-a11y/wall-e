# 启动语音提示

正常语音启动流程播放两段本地提示：

1. “瓦力正在启动，请稍候。”
2. “瓦力准备好了，可以叫我了。”

启动器优先创建现有音频播放节点，其他节点保留原有相对启动顺序。第一段在播放器可用后排入现有混音输出，运行时不调用在线 TTS，也不增加第二个音频设备拥有者。

第二段等待本次启动会话的 LLM／直接音频服务、STT（当前模式需要时）、TTS 播放服务、音频播放节点和实际麦克风采集就绪。麦克风状态由真实采集拥有者收到首段 PCM 后确认，共享消费者不能代报。此状态表示本地语音路径准备完成，不验证云端 API 连通性或首次请求延迟。

提示播放时使用独立识别门控，包含音频前导静音和短尾音保护，防止“瓦力”唤醒自己。原始采集、AEC 和远程对讲继续运行；已开始的用户语音缓冲和识别回调会保留，提示不会单独调用识别引擎的暂停／取消。门控不覆盖对话 busy、游戏或远程状态。播放回调丢失或播放进程退出时，门控有界释放，不能永久停用识别。

用户说话、ASR 在途、识别结果向 LLM 交接、已有前景音频和远程对讲均优先于可选提示。提示不依靠固定倒计时判断识别完成。直接音频模式若用户已开始交互，会放弃延后的就绪提示以保护该对话。

每次启动使用独立临时会话和组件 PID，单个节点重启不会反复播报旧提示；退出启动器后清理会话。单独运行节点、键盘模式和纯远程采集诊断模式保持原行为，不启用该提示流程。

## 素材维护

素材是 48 kHz、单声道、16-bit PCM WAV，沿用现有 `zh-CN-YunxiaNeural` 音色：

- `assets/startup_begin.wav`
- `assets/startup_ready.wav`

需要重新合成时，在项目根目录运行：

```powershell
python generate_wake_response.py startup_begin.wav startup_ready.wav
```

此维护命令需要网络；运行端播放这些文件无需联网。提示通过现有 system 分类混音，不发送虚假的对话结束或 `llm_busy=idle`。

日志中的“播放启动提示音”表示已排队，“启动提示音队列完成”表示播放时间线结束；扬声器不可用时，现有混音器仍可能结束队列，因此日志完成不等于现场一定听到声音。
