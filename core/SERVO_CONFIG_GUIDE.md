# 瓦力 (Wall-E) 舵机配置说明与限位指南

本文档用于详细解释 `core/config.yaml` 中关于 **舵机 (servos)** 的配置项，特别是 `limit_1` 和 `limit_2`（物理限位）的设计原理与调试方法。

## 1. 舵机基础概念与 PWM 值

瓦力的所有舵机均由 PCA9685 驱动板统一管理。在底层 Python 代码（使用了 Adafruit 库）中，PWM 的占空比是被映射为 **16-bit (0-65535)** 的数值。
在标准 50Hz 刷新率（20ms 周期）下，标准舵机的脉冲宽度与代码里的 PWM 数值对应关系如下：
- **0.5ms (通常为 0 度极限)** ≈ `1638`
- **1.5ms (通常为 90 度中位)** ≈ `4915`
- **2.5ms (通常为 180 度极限)** ≈ `8192`

由于瓦力内部空间狭小，且采用了复杂的联动机械结构，**绝对不能让舵机强行转到物理死角并发生堵转 (Stall)**，否则极其容易烧毁舵机或折断打印件。因此，所有的运动范围都必须被严格框定在安全数值内。

## 2. Config.yaml 配置结构解析

在 `core/config.yaml` 中，针对每一个舵机，都有如下标准的配置块：

```yaml
  - id: 4             # 舵机接在 PCA9685 上的硬件通道号 (0-15)
    name: "head_yaw"  # 逻辑名称，代码中通过该名称索引此舵机（如 头部左右旋转）
    limit_1: 1920     # 物理限位 A (16-bit PWM 原始值)
    limit_2: 7600     # 物理限位 B (16-bit PWM 原始值)
    init: 5000        # 开机/复位时的初始中立位置 (16-bit PWM 原始值)
```

## 3. 为什么是 `limit_1` 和 `limit_2`，而不是 `min` 和 `max`？

你可能会注意到，部分舵机的 `limit_1` 比 `limit_2` 大（例如 `eye_l` 的 `limit_1: 7500`, `limit_2: 5000`），这**绝对不是写反了**，而是由于机器人的**对称机械设计**决定的。

1. **机械反向安装**：瓦力的左右手臂、左右眼睛、左右眉毛在物理上通常是镜像对称安装的。
2. **逻辑统一映射**：如果我们在逻辑上要求“向外转”是 0%，向内转是 100%。对于右眼可能是 PWM 从小到大，但对于左眼，PWM 必须是从大到小。
3. **限位即映射**：
   - `limit_1` 代表了逻辑上的 **0% 行程**（或者是 `0度` 端点）。
   - `limit_2` 代表了逻辑上的 **100% 行程**（或者是 `180度` 端点）。
   - 如果发生镜像反向，只需调换 `limit_1` 和 `limit_2` 的数值大小，上层控制代码就能够自动实现“反相”映射，不需要写任何 `if (is_left)` 的恶心代码。

## 4. 各部位限位调节参考与安全警告

如果你更换了舵机或者重新组装了机械件，请务必按照以下步骤重新寻找限位：

### 4.1 头部云台 (`head_yaw`, `neck_top`, `neck_bottom`)
- `head_yaw` (头部偏航/左右转)：范围较宽，但如果转得太后，线缆可能会被扯断。
- `neck_bottom` & `neck_top` (脖子上下仰俯)：**极其重要！** 脖子的双舵机连杆机构存在物理死点，数值一旦超出安全范围（如 `neck_bottom` < 3000 或 > 7500），舵机会相互卡死干涉，瞬间发烫，务必微调。

### 4.2 眼睛组件 (`eye_l`, `eye_r`)
- 这是瓦力最脆弱的部位。眼眶外翻和内收的范围很小（比如 `2000` 到 `4300`）。
- **注意镜像**：`eye_r` (2000 -> 4300) 和 `eye_l` (7500 -> 5000) 方向是相反的。

### 4.3 眉毛组件 (`eyebrow_l`, `eyebrow_r`)
- 控制表情的核心。同样是镜像安装。
- 如果发现眉毛在开心（上扬）的时候反倒往下撇了，直接在 yaml 中互换该舵机的 `limit_1` 和 `limit_2` 的值即可瞬间修复。

### 4.4 手臂 (`arm_l`, `arm_r`)
- 瓦力手臂的槽位行程有限，千万不可直接设定为极限 `1638` 到 `8192`。应在 `2000` 到 `6000`（或 `8000` 到 `4000`）之间打底。

## 5. 如何安全地测量新限位？

当你更换部件后，千万不要立刻运行主控进程。请通过独立的调试脚本，每次以 `100` 为步进，一点一点测试边界。

**建议做法：**
1. 先断开舵机与机械臂的连杆（或者将舵机盘拔出）。
2. 让舵机转到 `5000` (正中位)。
3. 套上机械臂（或舵机盘），让机器人的物理形态处于正中间（比如直视前方、手臂平放）。
4. 挂载机械臂后，用脚本一点点减小或增大数值（如 `5000 -> 4800 -> 4500`）。
5. **听声音**：一旦听到舵机发出尖锐的“滋滋”电流声，或者肉眼看到机械件发生形变干涉，**立刻停止**并退回 `200` 个单位。这个退回后的数值，就是你的绝佳 `limit` 值。
6. 将找到的安全极值填入 `config.yaml`。
